# Social Network Ads Prediction using Logistic Regression

## 📌 Project Overview

This Machine Learning project uses **Logistic Regression** to predict whether a user will purchase a product based on their demographic information from a social network advertising dataset.

The model analyzes user features such as **Age** and **Estimated Salary** to classify purchase behavior.

---

## 🎯 Objective

To build a classification model that predicts whether a customer will purchase a product after seeing a social network advertisement.

---

## 📊 Dataset

The dataset contains the following features:

- User ID
- Gender
- Age
- Estimated Salary
- Purchased (Target Variable)

Target Variable:
- 0 → Not Purchased
- 1 → Purchased
